# F407 BoardBringup

STM32F407VET6 主控板与串口屏单项测试工程，打开 `MDK-ARM/F407_BoardBringup.uvprojx` 编译。它与电机工程是两套独立固件。

USART1 为电脑调试终端（PA9/TX、PA10/RX），USART3 为串口屏（PD8/TX、PD9/RX），波特率均为 115200。LED 周期翻转并输出日志；PC1 输入经消抖后计数。串口屏页面需要存在文本组件 `t0` 和数字组件 `n0`。

上电向屏幕发送 `t0.txt="STM32 OK"` 和 `n0.val=0`。在电脑终端用文本发送一条屏幕指令并回车，固件会通过 USART3 转发，并自动附加三个二进制 `FF` 结束字节。例如发送 `n0.val=123`。不要把结束字节作为文本手动追加。

PC1 每次有效按下会更新计数并写入屏幕 `n0`。接线、电平和屏幕工程需与现场实物对应。

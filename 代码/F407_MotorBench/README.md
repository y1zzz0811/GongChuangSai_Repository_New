# F407 MotorBench A1

STM32F407VET6 电机与底盘调试工程。USART1 为电脑终端，USART2 为电机总线，USART6 尚未启用。上电不自动运动。

唯一操作手册：[电机与底盘调试统一操作手册](../电机与底盘调试统一操作手册.md)。今后指令只在该手册维护，README 不复制另一份指令清单。

持久默认参数集中在 `Core/Inc/chassis_config.h`：前后轮中心距190mm、左右轮中心距215mm、轮径80mm、16细分、实测方向{1,0,0,1}。修改宏后重新编译下载；终端临时配置仅存在RAM，复位恢复宏默认值。

A方案为非阻塞位置控制状态机：四台预检查、配置验证、同步预装、统一触发、状态与实际位移确认、动作间停顿。方形路线为前进后原地右转90度，重复四次。尚未接入陀螺仪，地面距离/转角及回原点误差需实测标定。

USART1/2使用单字节中断接收与环形缓冲；中断入口及NVIC配置保存在CubeMX用户区。更新时重新加载全部修改文件；不要仅复制motor_bench.c而遗漏中断配置。

`Tests/host/test_motorbench.c` 使用模拟HAL和电机协议测试实际的motor_bench.c；它不打开串口，也不会控制硬件。编译和主机测试通过不能代替实车验收。仓库不包含本机备份和编译缓存。

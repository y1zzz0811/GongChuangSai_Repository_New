# 工创赛 · 智能物流搬运机器人

本仓库用于「中国大学生工程实践与创新能力大赛（工创赛）」智能物流搬运赛道的团队协作与代码、资料管理。

## 项目简介

智能物流搬运机器人，基于 STM32F407 主控，集成双轴机械臂、物料转台、麦克纳姆轮底盘与视觉系统，实现物料的自主识别、抓取与搬运。

## 使用说明

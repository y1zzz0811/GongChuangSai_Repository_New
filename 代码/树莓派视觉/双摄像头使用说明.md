# 双摄像头二维码与编号圆环识别

在树莓派 Thonny 中打开 `/home/string/Documents/dual_camera_recognition.py`，按 F5 运行。运行前先停止其他占用摄像头的程序。

- 左侧：摄像头 1，`/dev/video0`，640×480，二维码识别。
- 右侧：摄像头 2，`/dev/video2`，800×600，识别黑色同心圆环中央的数字1、2、3并标记圆心。绿色十字始终标记图像中心。
- 两路均使用原脚本的 YUYV、10 FPS 配置。画面等比例缩放，不裁剪。
- 圆心坐标和偏差以摄像头 2 的实际采集分辨率计算；dx 向右为正，dy 向下为正。坐标未经镜头或透视标定。
- 空格或“拍照”按钮：将两路原图和识别结果保存到 `/home/string/Pictures/dual_recognition/`。两路各保存最近一帧，并非硬件同步拍照。
- Q、Esc 或关闭窗口：退出并释放两路摄像头。

程序复用 `dual_camera_preview.py`、`qr_camera1.py` 和 `target_center_camera1.py` 中的采集及绘图函数。新版编号靶需要把 `numbered_ring_detector.py` 与 `numbered_ring_templates.png` 放在 `dual_camera_recognition.py` 的同一目录。

新版使用局部对比度找黑色环线，拟合内边界并验证外侧同心环，再匹配环内数字。数字模板来自实拍靶标，支持倒置数字。相近位置连续三张新画面读号一致后显示编号与圆心。短暂读不清数字时，匹配唯一且轮廓连续可沿用编号最多两帧、0.6秒。橙色十字表示位置或编号仍待确认。编号冲突、靶标丢失或位置跳变时重新确认。

现有彩色识别模块保留作独立参考，蓝色漏检修复记录见 `蓝色识别修复说明.md`。

四张编号靶附件已做离线回放。它们包含旧版预览文字、阴影、倒置数字和边缘截断。像素坐标用于显示和验证，毫米测量需要后续标定。

默认保留原二维码串口功能：`/dev/serial0`，115200、8N1，数据包 `QR,253+231+532+132\n`。只有唯一、合法的二维码连续三次识别一致才发送；同一码持续出现只发送一次，完全消失至少一秒后允许重发。圆圈数据只显示在画面中。

串口不可用时界面会显示原因，两路识别继续运行。需要重新打开串口时，退出并重新运行程序。

只识别、不发送串口数据：将文件顶部 `ENABLE_UART = True` 改为 `False`，或者在树莓派终端运行：

```bash
cd /home/string/Documents
python3 dual_camera_recognition.py --no-uart
```

如果摄像头的物理顺序相反，交换文件顶部 `CAMERA_DEVICES` 的两个路径。为保持插拔后的设备身份，也可使用 `/dev/v4l/by-path/` 下各摄像头的 `video-index0` 路径。

无窗口检查两路相机（不发送串口）：

```bash
python3 dual_camera_recognition.py --no-uart --headless --duration 10
```

算法与串口规则回归检查（不打开摄像头或串口）：

```bash
python3 -m unittest -v test_dual_camera_recognition.py test_target_center_detector.py
```

## 毫米测量

固定机械臂的回转、升降和伸缩，使用与标定时相同的镜头设置和采集尺寸。新版本需要同目录中的 `ring_metric.py`。提供标定文件后，可用以下命令检查偏差。

```bash
python3 dual_camera_recognition.py --no-uart --ring-metric ring_metric.json
```

标定 JSON 需要以下字段。

| 字段 | 数据 |
|---|---|
| `image_size` | `[宽度, 高度]`，以标定所用相机2的实际原图为准 |
| `camera_matrix` | 镜头标定得到的3×3相机矩阵 |
| `dist_coeffs` | 同一次标定得到的 OpenCV 畸变系数数组 |
| `ground_marks` | 至少4个分布开且不共线的水平标定点，每行 `[u, v, 前方坐标, 左侧坐标]`。坐标可使用同一棋盘格单位，原点可选任意棋盘角点。TOP和RAW双摄使用10 mm格长 |
| `diameters_mm` | 以编号字符串为键，以毫米为值，例如 `"2"` 对应2号靶紧挨数字白区的最内圈内缘实测直径 |

Z=184 mm 的初版配置已保存为 `calibration_samples/ring_metric_Z184_image_center.json`。它使用居中的平放棋盘图建立车体方向，以800×600原图中心 `(399.5, 299.5)` 作为夹爪零点，并按三个地面靶内缘均为50 mm换算。将该配置和新版程序复制到树莓派后，通过 `--ring-metric ring_metric_Z184_image_center.json` 载入。

把有尺寸的平面网格按车头前方和车体左侧摆正，在当前观察姿态拍摄相机2原图。逐点记录原图像素和对应的前后、左右实测坐标。旧JSON的 `zero_pixel` 字段会被忽略。

软件从标定点求相机在车体坐标中的位置和方向，再用对应环径恢复水平尺度。显示 `Fwd` 和 `Left` 两个分量，负数分别表示后退和右移。圆心确认但环边证据不足时显示 `MM UNAVAILABLE`。绿色十字是画面中心，也是统一的夹爪零点。

先用地面上的独立位置检查零点和方向。分别将靶标沿车头前方和车体左侧移已知距离，检查该轴的读数变化与尺量值一致，并记录另一轴的串扰。测试底盘时，先按其中一轴小步移动，停稳重新取样，再修正另一轴。更换机械臂观察姿态后使用对应的标定文件。

# PWM Servo（早期 F103 测试）

适用于 STM32F103C8/CB，打开 `MDK-ARM/PWM_Servo.uvprojx`。此工程保留本地已有实现，未移植到当前 STM32F407 主控板。

TIM2_CH1 通过 PA0 输出 PWM，定时器分频 71、周期 19999，在原工程 72 MHz 定时器时钟下产生约 50 Hz 信号。`Servo_SetAngle()` 将角度映射为脉宽；上电后循环输出 0°、90°、180°，每档停留 1 秒。

该固件没有串口启动或停止命令，下载并运行后会自动驱动舵机。应先核对舵机脉宽与机构行程，单独测试时断开负载；电源容量与接地按实际舵机要求设置。
